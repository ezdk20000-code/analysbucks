# AnalysBucks — прогнозы футбольных матчей и система ставок

АПЛ и Ла Лига. Прогноз исходов, поиск value-ставок (ординары и экспрессы), управление
банком по Келли с лимитами риска, учёт ставок, дашборд и Telegram-бот.
Используются только бесплатные источники данных.

---

## Что показало исследование (честно)

Проверка шла на 17 сезонах (2010–2026, 12 000+ матчей) с реальными коэффициентами букмекеров.

1. **Рынок точнее любой модели на публичной статистике.** Средний коэффициент
   букмекеров без маржи даёт log-loss 0.958. Наша модель (Dixon–Coles + форма,
   усталость, переезды, мотивация, погода) даёт 0.972, смесь с рынком тоже не лучше.
   Поэтому вероятность для ставок берётся из **рынка**, а модель работает как второе мнение.

2. **Маржу нужно вычитать степенным методом.** Букмекеры закладывают больше маржи в
   кэфы на аутсайдеров, чем на фаворитов. Степенной метод это учитывает и откалиброван
   почти идеально (вкладка «Рейтинги» → «Честность рынка»).

3. **Главное преимущество — лучший коэффициент на рынке (line shopping).** Если брать
   справедливую вероятность по среднему рынку, а ставить по лучшему кэфу среди букмекеров,
   появляется устойчивый перевес. Так работают профессиональные value-беттеры.

4. **Экспрессы.** Слепой экспресс из фаворитов по среднему кэфу на 16 сезонах даёт
   −1…−4% ROI. С отдельными сезонами от −60% до +155% — это удача, а не система.
   Экспресс из 2–3 событий, *у каждого из которых есть перевес*, — лучшая стратегия в
   бэктесте: перевесы перемножаются (1.03 × 1.03 × 1.03 ≈ +9%). Экспрессы из 4+ событий
   в бэктесте хуже: дисперсия съедает перевес.

5. **Геометрический рост — это критерий Келли.** Полный Келли дал рост банка ×16 за 14 лет,
   но с просадками до 37%. Четверть Келли (по умолчанию) — ×3–4 при просадке ~18%.

### Бэктест настроек по умолчанию (2012/13 – 2026/27, старт 1000)

| Показатель | Значение |
|---|---|
| Ставок (ординары + экспрессы по 3) | 1424 |
| ROI на оборот | +7.6% |
| Рост банка | ×3.8 (≈ +10% в год) |
| Максимальная просадка | 18% |
| CLV (наш кэф против закрытия линии) | +4.8% |
| Монте-Карло: 5% худших исходов | ×2.0 |

### Риски, о которых нужно помнить

- **Лучший кэф** в данных football-data — максимум среди многих букмекеров. Чтобы его
  получать, нужны счета у нескольких контор. Если у вашего букмекера кэф ниже
  рекомендованного, перевес может исчезнуть. Не ставьте ниже указанного кэфа.
- Букмекеры **режут лимиты** выигрывающим игрокам.
- Параметры подобраны на той же истории, поэтому вживую результат будет **хуже бэктеста**.
- В сезонах 2025/26 и 2026/27 value-ставок стало заметно меньше (12 и 20), а 2026/27 пока
  в минусе. Следующий шаг — собственный сбор коэффициентов (см. «План»).
- **Порядок запуска:** 1–2 месяца виртуальных ставок (`paper`) → проверка CLV > 0 →
  реальные деньги малыми суммами.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env        # для бота
python -m abx update        # скачать данные (17 сезонов), ~1 мин
```

## Использование

```bash
python -m abx predict                        # прогнозы + рекомендуемые ставки на ближайшие матчи
python -m abx match "Arsenal" "Chelsea"      # прогноз любой пары
python -m abx table EPL                      # рейтинги силы
python -m abx backtest                       # бэктест текущих настроек
python -m abx backtest --mode express --legs 2 --kelly 0.5
python -m abx deposit 1000                   # банк
python -m abx take 3                         # записать рекомендацию №3 (виртуально)
python -m abx take 3 --real --stake 25       # как реальную ставку
python -m abx bet --home Sevilla --away Betis --market OU25 --sel U --odds 1.86 --stake 10 --real
python -m abx bank                           # банк и статистика (ROI, CLV)
python -m abx settle 5 won                   # ручной расчёт
streamlit run dashboard/app.py               # дашборд
python -m bot.bot                            # Telegram-бот
```

Рынки и исходы: `1X2` — `H` (П1), `D` (X), `A` (П2); `OU25` — `O` (ТБ 2.5), `U` (ТМ 2.5).

### Telegram-бот

1. Создайте бота у @BotFather и запишите токен в `.env` → `TELEGRAM_BOT_TOKEN`.
2. Запустите `python -m bot.bot` и напишите боту `/start`: он ответит вашим chat id.
3. Впишите chat id в `TELEGRAM_ALLOWED_CHATS` и перезапустите бота.

Команды: `/predict`, `/take N [сумма]`, `/takereal N [сумма]`, `/match Arsenal - Chelsea`,
`/bank`, `/bets`, `/settle ID won|lost|void`, `/deposit`, `/withdraw`, `/update`, `/table`.

### Автоматизация (cron)

```cron
# каждый день в 08:10 — обновить данные и рассчитать ставки
10 8 * * *  cd /path/analysbucks && python -m abx update
# пятница и вторник 12:20 — разослать рекомендации в Telegram
20 12 * * 2,5  cd /path/analysbucks && python -m abx notify
```

### Ручные поправки (травмы, мораль, смена тренера)

`data/manual/team_news.csv` (пример — `team_news.example.csv`): множители ожидаемых
голов команды на период. Используются в прогнозе пары (`match`) и видны в боте.
Свои матчи с коэффициентами можно добавить в `data/manual/fixtures.csv`
(пример — `fixtures.example.csv`).

## Как устроено

```
abx/
  data.py       football-data.co.uk: результаты, удары, коэффициенты (открытие/закрытие)
  teams.py      координаты стадионов (погода, расстояние переезда)
  weather.py    Open-Meteo: температура, осадки, ветер в час матча
  ratings.py    Elo и Dixon–Coles (атака/защита, затухание по времени, xG-прокси по ударам)
  features.py   форма, «удача» (голы − xG), серии, отдых, нагрузка, переезд,
                мотивация по таблице (титул / вылет / «играть не за что»)
  model.py      walk-forward: DC → логистическая регрессия на признаках → смесь с рынком
  odds.py       вычет маржи (степенной метод)
  betting.py    отбор value-ординаров и экспрессов, симуляция, Монте-Карло
  staking.py    Келли / % банка / флэт, лимиты: на ставку, на экспресс, на день,
                тормоз при просадке, стоп-лосс
  ledger.py     учёт ставок и банка (SQLite), авторасчёт по результатам, CLV
  service.py    общий слой для CLI, дашборда и бота
dashboard/app.py   Streamlit
bot/bot.py         Telegram (long polling)
config.yaml        все настройки
```

Настройки стратегии и риска находятся в `config.yaml`. Каждый параметр прокомментирован.

## План развития

1. **Собственный сбор коэффициентов** у нескольких букмекеров (включая доступные вам) с
   фиксацией времени. Это главное: перевес идёт от лучшего кэфа и раннего входа.
2. **Составы и травмы** за 1 час до матча → автоматические поправки.
3. **Новости и пресс-конференции → LLM** → структурированные сигналы (конфликты,
   ротация, мотивация).
4. **Еврокубки и кубки** в календаре → точнее учёт усталости.
5. **Мониторинг CLV** вживую — главный индикатор того, что перевес реальный.
